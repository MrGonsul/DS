# Data Structure

## Overview

This repository contains C++ implementations of fundamental Data Structures and Sorting Algorithms. It was created for learning, practicing, and understanding core data structure concepts.

## Contents

### Arrays
- 1D Array
- 3D Array

### Linked Lists
- Singly Linked List
- Doubly Linked List
- Circular Singly Linked List
- Circular Doubly Linked List
- Queue using Linked List
- Circular Queue using Linked List
- Binary Search Tree as Linked List

### Sorting
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Practice Files
The repository also includes several idea and practice files for solving data structure problems recursively and iteratively.
